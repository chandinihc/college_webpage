# 🎓 COLLEGE WEBSITE

## 📌 ABOUT THE PROJECT

The College Website is a web-based project designed to provide students, faculty, parents, and visitors with important information about the college.

## 🎯 OBJECTIVES

- To provide college information in one place.
- To display academic programs and campus facilities.
- To make important information easily accessible.

## ✨ FEATURES

### 🏠 Home Page

Introduction to the college.

### 📚 Courses

Details about available academic programs.

### 🏫 Facilities

Information about campus facilities and resources.

### 🖼️ Gallery

Photos of campus events and activities.

### 📞 Contact Us

Contact information for students and visitors.

## 🛠️ TECHNOLOGIES USED

- HTML
- CSS
- JavaScript

## 🚀 HOW TO RUN

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.

## ✅ CONCLUSION

This project provides a simple and accessible platform for displaying college information online.
